# .github

Dev-Forge-Group의 조직 공통 자료다.

| 경로 | 쓰임 |
|---|---|
| `profile/README.md` | 조직 페이지의 소개 |
| `CONTRIBUTING.md` | 자체 문서가 없는 저장소에 적용되는 기여 규칙 |
| `.github/pull_request_template.md` | 자체 양식이 없는 저장소의 PR 양식 |
| `.github/workflows/commit-attribution.yml` | 커밋 작성자 표기 검사. 각 저장소가 `uses: Dev-Forge-Group/.github/.github/workflows/commit-attribution.yml@main`로 호출한다 |

공개 저장소이므로 내부 운영 정보·비밀값·비공개 저장소의 세부 내용은 넣지 않는다.
